# Five-minute interview walkthrough

1. Sign in as owner and open Studio North → Website refresh.
2. Open a second browser profile as member, on the same project.
3. Move a task with the drag handle or task stage dropdown; both views update.
4. Create a task assigned to member; show the live notification.
5. Add a comment and show activity.
6. Remove the member and show API/socket access being denied.

Discuss: tenant isolation, optimistic rollback, version conflicts, authenticated rooms and database-backed reconnects.
